# 🍄 Super Mario World – Unity 6 Remake

A faithful 2D remake of the original **Super Mario World (SNES)** developed in **Unity 6** using **C#** and Unity's **New Input System**.

Built as part of the course **“Programming for Games”** at the **Bezalel Academy of Arts and Design**, this project replicates the beloved platforming experience while introducing a unique new mechanic.

---

## 💻 Development

All code and systems were created from scratch as a learning experience, with occasional assistance from AI tools (like ChatGPT) for suggestions and debugging.

## 🌟 Exclusive Feature: Earth Quake Attack

Inspired by modern power-ups, this remake introduces a custom feature called the **Earth Quake**.

- Can only be activated while in **Super Mario state**
- Press `Space` to trigger
- Instantly defeats all nearby enemies
- Adds a tactical element to enemy encounters and boss fights
- Created using Unity physics and custom enemy handling

---

## 🕹️ Gameplay Features

- Classic side-scrolling **platformer** gameplay
- Jump on enemies to defeat them
- Collect coins to increase score
- Power-ups and state upgrades (Small Mario → Super Mario)
- Enemy collision detection
- Custom Earth Quake mechanic
